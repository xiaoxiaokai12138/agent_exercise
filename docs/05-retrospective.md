# 复盘

## 最难的问题

模型会把工具状态和任务终态混用。初版中，模型在选择保存动作时提前声明完成。随后一次实跑里，模型看到时段冲突就选择阻断，理由也误写成审核风险。这两个问题都通过实际 Trace 发现。

## 学习收获

用单一枚举表达每轮的动作，可以消除互相矛盾的字段组合。执行器可以校验模型提出的动作和结论，把拒绝作为下一轮观察。对写操作，保存结果要以 SQLite 事务返回为准；即使执行预算耗尽，也要把已落库状态如实返回。
